11.3.3

Para elementos circulares, el área usada para calcular Vc debe tomarse como el producto del diámetro y el peralte efectivo d de la sección de concreto. Se permite asumir que el peralte efectivo de la sección de concreto equivale a 0,80 veces el diámetro de la sección de concreto.

VER RESPUESTA

C) Cero · Art. 11.3.1.3

Para elementos sometidos a tracción axial significativa, Vc debe tomarse como cero a menos que se haga un análisis más detallado usando 11.3.2.3.
